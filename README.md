# وِشّ — متجر الأمنيات الافتراضي

واجهة MVP عربية RTL لمتجر ترفيهي يتيح محاكاة شراء منتجات افتراضية بأسعار رمزية. لا يوجد شحن أو توصيل أو دفع حقيقي.

## التشغيل المحلي

يتطلب Node.js 18.17 أو أحدث:

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## النطاق

- صفحة هبوط عربية متجاوبة ومناسبة لحركة المرور من TikTok.
- كتالوج محلي مصنف مع بحث وتصفية.
- سلة افتراضية وحساب الإجمالي بالهللات والريال.
- تدفق Checkout تجريبي واضح بأنه غير حقيقي.
- قسم مكافآت وإعلانات اختياري في التنقل، بدون إعلانات مزعجة.
