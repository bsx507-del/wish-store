# وِشّ — متجر اللحظات الرقمية

واجهة عربية RTL لمتجر ترفيهي يبيع لحظات وهدايا رقمية بأسعار رمزية. النسخة الحالية تعرض تجربة الدفع وتسجيل البريد محليًا، بينما ربط الدفع الحقيقي يحتاج حسابًا لدى Stripe أو Moyasar ومفاتيح سرية على الخادم.

## التشغيل المحلي

يتطلب Node.js 18.17 أو أحدث:

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## النطاق

- صفحة هبوط عربية متجاوبة ومناسبة لحركة المرور من TikTok.
- كتالوج محلي مصنف مع بحث وتصفية.
- سلة افتراضية وحساب الإجمالي بالهللات والريال.
- حساب بالبريد الإلكتروني فقط محفوظ محليًا في نسخة الـMVP.
- قسم نموذج العمل ومسارات الدخل: المنتجات الرقمية، العضوية، والهدايا.
- مكافأة يومية اختيارية بدون إعلانات مزعجة.
- المكافأة اليومية تضيف ٢٥ هللة فعلية إلى الرصيد التجريبي وتُقفل حتى اليوم التالي.
- خلفية تفاعلية هادئة تتبع مؤشر الماوس مع وضع ثابت تلقائيًا للأجهزة اللمسية وتقليل الحركة.
- محفظة تجريبية محفوظة محليًا مع شحن رمزي وتحقق من الرصيد قبل إتمام الطلب.
- سجل طلبات محلي يعرض رقم الطلب والتاريخ والمنتجات والإجمالي بعد كل عملية محاكاة.
- مفضلة محلية ومشاركة المنتجات، مع أسئلة شائعة وشروط وخصوصية داخل الواجهة.
- فرز المنتجات حسب السعر أو الاسم، مع فلتر سريع للمفضلة.
- بحث عربي مرن يتجاهل اختلافات الهمزات والتاء المربوطة، مع حالة فارغة قابلة لإعادة الضبط.
- زر تفريغ للسلة وتحسينات إضافية لتجربة الجوال.
- روابط المشاركة تفتح تفاصيل المنتج مباشرة، مع اقتراحات مشابهة داخل نافذة المنتج.
- حماية من النقر المكرر أثناء حفظ الطلب التجريبي.
- نافذة المنتج تنعكس في رابط الصفحة، لتعمل روابط المشاركة والرجوع دون فقدان المنتج المختار.
- البحث والتصنيف والفرز والمفضلة تنعكس أيضًا في الرابط، لتسهيل مشاركة قائمة مختارة.
- لا يوجد شحن أو تسليم؛ كل المنتجات والطلبات افتراضية للترفيه فقط.

## كيف يتحول إلى منتج مدفوع؟

1. اختر مزود الدفع: Stripe للبطاقات العالمية أو Moyasar للسعودية.
2. أضف API route على الخادم لإنشاء Checkout Session، ولا تضع مفاتيح الدفع في الواجهة.
3. استبدل زر «متابعة للدفع عند الإطلاق» برابط جلسة الدفع.
4. استخدم Supabase Auth أو Clerk لتسجيل البريد الحقيقي بدل التخزين المحلي.
